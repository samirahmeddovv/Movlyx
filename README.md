# Movlyx 🎬🍿

**Movlyx** is a modern movie explorer web application designed to help users discover films, browse details, and manage their movie preferences. Built using Python/Flask and integrated with an Oracle Database, it fetches dynamic content via external movie APIs (like TMDB).

## 🚀 Key Features
* **Movie Discovery & Search:** Browse trending movies, top picks, and search for specific titles instantly.
* **Detailed View:** Check movie overviews, ratings, release dates, and genres.
* **Database Integration:** Stores user data, favorites, or custom watchlists securely using Oracle Database.
* **Clean Web Interface:** A responsive and intuitive UI powered by HTML, CSS, and JavaScript.

## 🛠️ Built With
* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript
* **Database:** Oracle Database (Oracle SQL Developer)
* **API:** TMDB (The Movie Database) API
